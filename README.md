# ProHactive

> Run Your Day Like a System.

A daily schedule manager built for people who actually want to get things done. 
Time-blocked tasks, priority levels, and smart notifications — all in one place.

## Tech Stack

- React + Tailwind CSS
- Context API + useReducer
- Web Notifications API
- localStorage (MVP)
